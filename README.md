# sr-core

The parts of scene-render that belong to no single engine:

| Path | What |
|---|---|
| [schema/](schema/) | **The canonical scene-render XSD and Schematron.** Engines vendor these exact files ([SHA256SUMS](schema/SHA256SUMS)); they change only through an SREP |
| [docs/schema/](docs/schema/index.html) | The static HTML reference of the schema, generated by `sr-schemadoc`; do not edit |
| [srep/](srep/) | Scene Render Enhancement Proposals: [SREP 0](srep/srep-0000.md) (the process), the [template](srep/srep-template.md) and the [index](srep/index.md) |
| [sr_core/vpkg/](sr_core/vpkg/) | `scenerender-vpkg`, the reference implementation of [SREP 1](srep/srep-0001.md), scene video packages (`.vpkg.zip`) |
| [sr_core/schemadoc/](sr_core/schemadoc/) | `sr-schemadoc`, which generates `docs/schema/` from `schema/` |
| [docs/vpkg-howto.md](docs/vpkg-howto.md) | How to package a video and rebuild one from a package |

```bash
pip install -e ~/src/sr-core          # installs scenerender-vpkg; standard library only
python3 -m sr_core.vpkg --help        # or without installing, from this folder
python3 -m sr_core.schemadoc         # regenerate docs/schema after changing schema/ (--check: is it current?)
python3 -m pytest tests               # vpkg (SREP 1) and schemadoc tests; fails if docs/schema is stale
```

## Versions

Three Semantic Versioning lines, each moving only when its own contract changes ([SREP 4](srep/srep-0004.md)):

| Line | Now | Where | Changelog | Tag |
|---|---|---|---|---|
| sr-core (commands, options, exit codes, outputs, reference URLs) | 1.0.0 | `sr_core.__version__` | [CHANGELOG.md](CHANGELOG.md) | `vX.Y.Z` |
| scene schema (documents declare MAJOR.MINOR: `version="1.1"`) | 1.1.1 | `xs:schema/@version` | [schema/CHANGELOG.md](schema/CHANGELOG.md) | `schema-X.Y.Z` |
| package format (`formatVersion`) | 1.0 | `vpkg.json` | [SREP 1](srep/srep-0001.md) | |

The Python modules are internal. Nobody picks version numbers by hand. Record each change under **Unreleased**
in its changelog, as Breaking, Added or Fixed, and let the release tool compute the bump:

```bash
python3 tools/release.py check                 # every version agrees; hashes and reference are current
python3 tools/release.py next schema           # what the Unreleased entries call for (PATCH unless they add or break)
python3 tools/release.py release schema        # cut it: changelog, version, SHA256SUMS, docs/schema; prints the tag
```
