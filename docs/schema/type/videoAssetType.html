    videoAssetType

    Type of <video> in assetsType

    Content

    • in this order
      1. <representation>any number

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Name by which layers refer to this video; an audio track may also name it when hasAudio is true.

    src requiredxs:anyURI

    Path of the video file; a remote URL is not fetched when rendering and is reported as an error.

    width requiredxs:positiveInteger

    Width in pixels that layout uses for the video frame.

    height requiredxs:positiveInteger

    Height in pixels that layout uses for the video frame.

    fps requiredfpsType

    Frame rate of the video in frames per second, an integer or a fraction such as 30000/1001; source time is turned into frame numbers with it.

    duration requiredpositiveDecimal

    Length of the video in seconds; the layer's playable source length runs from its clipIn to its clipOut, or to this duration.

    colorSpacecolorSpaceTypesrgb

    Colour primaries of the video's frames, used to convert them to the working space. Default srgb.

    transfertransferTypeauto

    Transfer curve of the video's frames; auto uses the curve tagged in the file, else the usual curve for the colour space.

    alphaalphaModeTypeauto

    How the video's alpha is read; ignored (opaque) when the file has no alpha channel. Default auto.

    hasAudioxs:booleanfalse

    If true, the video's audio track is mixed into the output; an audio track may name this video only when this is true. Default false.

    audioStreamxs:nonNegativeInteger0

    Index, counted from 0, of the file's audio stream to mix when hasAudio is true. Default 0.

    timecodeStarttimecodeType

    Timecode of the first frame of the file at its own fps; the render report lists, for each layer that plays the video, the source in and out timecodes derived from it and clipIn and clipOut, with a TIMECODE warning when they cannot be labelled. Decoding ignores it.

    pixelAspectpositiveDecimal1

    Width of a source pixel relative to its height; a layer showing the video is laid out width times pixelAspect by height, so anamorphic footage is widened. Default 1.

    rotationone of 0 90 180 2700

    Clockwise rotation in degrees (0, 90, 180 or 270) applied to the decoded frames; 0 uses the orientation recorded in the file.

    from attribute group assetProvenance
    sha256sha256Type

    SHA-256 digest of the source file, in hex. A local file is hashed when the scene is validated and a different digest is an error; a remote URL is not checked.

    licensexs:string

    Licence of the asset file as free text; copied into the render report's asset credits together with credit, and never checked.

    creditxs:string

    Attribution for the asset file as free text; copied into the render report's asset credits. An asset with neither license nor credit is left out of that list.

    proxyxs:anyURI

    Path of a lighter stand-in file. Rendering with the representation proxy (output/@representation or the --representation option) decodes it instead of src for images, videos, meshes and mixed audio when no representation named proxy exists; it carries no colorSpace, transfer or language of its own. A missing proxy file is warning A01.
