    Type of <audio> in assetsType

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Name by which audio tracks refer to this audio file.

    src requiredxs:anyURI

    Path of the audio file, relative to the scene file; a file: URL also works. Other URLs are not fetched, so such a file cannot be mixed.

    durationpositiveDecimal

    Declared length of the file in seconds; when assets are verified, a probed length more than 0.05 s away is warning A09 and the file's own length is used.

    sampleRatexs:positiveInteger

    Declared sample rate of the file in hertz; when assets are verified, a different probed rate is warning A09. The mix runs at audioMix/@sampleRate, not at this value.

    channelsxs:positiveInteger

    Declared channel count of the file; when assets are verified, a different probed count is warning A09 and the file's own channels are mixed.

    languagelanguageTagType

    Language tag of the audio; it becomes the output audio stream's language for a track that plays this asset and declares no language of its own, when the selected representation declares none either.

    bpmpositiveDecimal

    Tempo of the audio in beats per minute; required by a track that fits the audio to a duration (fitToDuration).

    from attribute group assetProvenance
    sha256sha256Type

    SHA-256 digest of the source file, in hex. A local file is hashed when the scene is validated and a different digest is an error; a remote URL is not checked.

    licensexs:string

    Licence of the asset file as free text; copied into the render report's asset credits together with credit, and never checked.

    creditxs:string

    Attribution for the asset file as free text; copied into the render report's asset credits. An asset with neither license nor credit is left out of that list.

    proxyxs:anyURI

    Path of a lighter stand-in file. Rendering with the representation proxy (output/@representation or the --representation option) decodes it instead of src for images, videos, meshes and mixed audio when no representation named proxy exists; it carries no colorSpace, transfer or language of its own. A missing proxy file is warning A01.
