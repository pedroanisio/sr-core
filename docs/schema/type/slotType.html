    slotType

    Type of <slot> in lottieAssetType

    Overrides a Lottie slot (sid) or a named text/colour layer inside the animation.

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:string

    Id (sid) of the Lottie slot whose value this overrides.

    value requiredxs:string

    Replacement value, required: #RRGGBB or #RRGGBBAA sets a colour, a comma-separated list of numbers a static scalar or vector, and anything else is parsed as Lottie JSON (a bare value is wrapped as a static property). Only slots are overridden; named layers are not.
