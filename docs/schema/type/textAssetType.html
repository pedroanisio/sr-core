    textAssetType

    Type of <text> in assetsType

    Text content comes from @text or from span children (exactly one). {{name}} inside text is replaced by the value of parameter "name". autoFit shrinks and/or grows size within [minSize, maxSize] so the text fits width x height. background draws a box behind each block, line or word.

    Content

    • in this order
      1. <span>any number

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Name by which layers refer to this text.

    textxs:string maxLength 1048576

    The text to show. {{name}} is replaced by the parameter or repeat variable of that name and left as written if none exists. Used instead of span children when not empty.

    width requiredxs:positiveInteger

    Width in pixels of the text box. In horizontal text, lines wrap at it and are aligned within it; in vertical writing modes it is the extent across which columns are placed and overflow is measured.

    height requiredxs:positiveInteger

    Height in pixels of the text box. In horizontal text, vertical alignment and overflow are measured against it; in vertical writing modes lines wrap at it and are aligned within it.

    size requiredxs:double in (0, 4096]

    Base font size in pixels, from just above 0 to 4096; autoFit may scale it.

    stylexs:IDREF

    Id of a text style whose settings this text starts from; its own attributes override them, except colour and line height left at their defaults.

    colorpaintType#FFFFFFFF

    Text fill paint. Default white; a named style's colour is used when this is left at the default.

    alignone of start center end justifystart

    Alignment of each line along its length within the box: start (default), center, end or justify, which widens the spaces to fill every line except the last of a paragraph. Start and end follow the text direction.

    lineHeightxs:double in [0.1, 10]1.2

    Line spacing as a multiple of the font size, from 0.1 to 10. Default 1.2; with a named style, a value left at 1.2 defers to the style's line height.

    letterSpacingxs:double in [-4096, 16384]0

    Extra space in pixels added after every character (negative tightens), from minus the font size to 4 times the font size. Default 0.

    directionone of auto ltr rtlauto

    Base text direction: ltr, rtl, or auto (default) to detect it from the text.

    languagelanguageTagType

    Language tag of the text, used to pick language-specific glyph forms when shaping.

    verticalAlignone of top middle bottomtop

    Placement of the lines across the box: top (default), middle or bottom. In vertical writing modes it moves the columns sideways, with top at the side where the columns begin.

    writingModeone of horizontal-tb vertical-rl vertical-lrhorizontal-tb

    Line direction: horizontal-tb (default) lays lines out horizontally, vertical-rl and vertical-lr run text top to bottom with lines advancing right-to-left or left-to-right.

    wrapone of word character none balanceword

    How lines break at the box width: word (default), character (anywhere), none (only at explicit line breaks) or balance (evens out line lengths).

    hyphenatexs:booleanfalse

    If true, a word of at least five letters that overflows a line may break at an English hyphenation point, with a hyphen added. Default false.

    autoFitone of none shrink grow fitnone

    Scales the text to the box: shrink only makes it smaller, and only if it overflows; grow only larger, while it fits; fit does both. minSize and maxSize bound the scaling. Default none.

    minSizepositiveDecimal

    Smallest font size in pixels that autoFit shrink or fit may reach; 5 percent of the size when absent.

    maxSizepositiveDecimal

    Largest font size in pixels that autoFit grow or fit may reach; 8 times the size when absent.

    maxLinesxs:positiveInteger

    Maximum number of lines shown; later lines are cut off.

    overflowone of visible clip ellipsisvisible

    What happens to lines that do not fit in the box: visible (default) draws them anyway, clip cuts them at the box edge, ellipsis drops the lines that do not fit and ends the last kept line with an ellipsis.

    backgroundpaintType

    Paint of a box drawn behind the text. Default none.

    backgroundModeone of block line wordblock

    Shape of the background: block (default) one box around all the text, line one per line, or word one per word.

    backgroundPaddingnonNegativeDecimal0

    Padding in pixels added around each background box on every side. Default 0.

    backgroundRadiusnonNegativeDecimal0

    Corner radius in pixels of each background box. Default 0.

    emojione of color textcolor

    color (default) prefers a colour emoji font for emoji characters; text does not, so they come from the text's own font or the usual fallback.

    from attribute group characterStyle
    fontxs:string

    Comma-separated font family names for the text, tried in order; characters a family lacks fall back to later families.

    fontFilexs:anyURI

    Path of a font file used for the text instead of an installed family; a remote URL is not fetched and is ignored.

    fontAssetxs:IDREF

    Id of a font asset whose font file is used for the text.

    fallbackxs:string

    Comma-separated family names tried after the primary (first) font; replaces every later family, inherited or listed in font. A pinned font policy requires each to name a font asset.

    weightfontWeightType

    Font weight from 1 (thinnest) to 1000 (heaviest); 400 is regular and 700 bold. Default 400.

    fontStylefontStyleType

    Slant of the text: normal (upright), or italic or oblique, both of which select the italic face. Default normal.

    stretchpositiveDecimal

    Font width as a ratio of normal (1 = normal, below 1 condensed, above 1 expanded); a value above 4 is read as a percentage. Default 1.

    variationxs:string

    Variable-font axis settings as tag and value pairs, e.g. "wght 720, wdth 90".

    featuresxs:string

    Comma-separated OpenType feature tags to apply, e.g. "liga, tnum, ss01"; a leading minus turns a feature off.

    strokeColorpaintType

    Paint of the outline drawn around each glyph; an inherited colour is kept, else black when a stroke width or position is given. A colour alone gives a width of 6 percent of the font size unless one is inherited.

    strokeWidthnonNegativeDecimal

    Width in pixels of the glyph outline; 0 removes it. If a stroke colour or position is given without a width, 6 percent of the font size.

    strokePositionstrokePositionType

    Where the glyph outline sits relative to the glyph edge: center (default), inside or outside.

    shadowColorcolorType

    Colour of the drop shadow behind the glyphs. When absent, an inherited shadow colour is kept, else black at 60 percent opacity; any single shadow attribute switches the shadow on.

    shadowOffsetXxs:double

    Horizontal offset in pixels of the drop shadow from the glyphs; positive moves it right. Default 0.

    shadowOffsetYxs:double

    Vertical offset in pixels of the drop shadow from the glyphs; positive moves it down. Default 0.

    shadowBlurnonNegativeDecimal

    Softness of the drop shadow in pixels; 0 gives a hard-edged shadow. Default 0.

    baselineShiftxs:double

    Raises the text above its baseline by this many pixels (negative lowers it); has no effect in vertical writing. Default 0.

    trackingxs:double

    Extra space after each character in thousandths of the font size (negative tightens). Default 0.

    textTransformone of none uppercase lowercase capitalize small-caps

    Case transformation of the displayed text: none (default), uppercase, lowercase, capitalize (first letter of each word) or small-caps (the font's own small-capital glyphs, if it has them).

    decorationone of none underline line-through overline

    Line drawn on the text: none (default), underline, line-through or overline, in the text colour.

    highlightpaintType

    Paint of a box drawn behind each line of text carrying this style. Default none.
