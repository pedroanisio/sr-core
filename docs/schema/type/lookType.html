    lookType

    Type of <look> in colorManagementType

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Name by which colorManagement/@looks lists the look; with an OpenColorIO config, a look with no LUT or CDL values names a look of that config by this id.

    srcxs:anyURI

    Path of a local LUT file applied as the look; remote files are not supported. When absent the look is built from slope, offset, power and saturation.

    spacecolorSpaceTypeacescct

    Colour space in which the LUT file is applied; acescct when absent. Used only for LUT looks.

    slopexs:string

    ASC CDL slope: one number applied to all channels, or red, green and blue separated by commas or spaces; 1 when absent. Used only when the look has no LUT (src).

    offsetxs:string

    ASC CDL offset: one number for all channels, or red, green and blue separated by commas or spaces; 0 when absent. Used only when the look has no LUT (src).

    powerxs:string

    ASC CDL power (gamma): one number for all channels, or red, green and blue separated by commas or spaces; 1 when absent. Used only when the look has no LUT (src).

    saturationxs:double1

    ASC CDL saturation multiplier; 1 leaves colour unchanged. Used only when the look has no LUT.

    mixunitDecimal1

    Strength of the look from 0 (frame unchanged) to 1 (full look); 1 when absent. Not applied to a look that names a look of an OpenColorIO config.
