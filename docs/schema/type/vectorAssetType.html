    vectorAssetType

    Type of <vector> in assetsType

    shape="svg" renders the SVG file at @src (static SVG 2 subset, no script).

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Name by which layers refer to this vector shape.

    shape requiredone of rect ellipse path rounded-rect polygon star line svg

    Kind of shape drawn: rect, rounded-rect, ellipse, polygon, star, line, path (from path data) or svg (the file at src).

    srcxs:anyURI

    Path of the SVG file drawn when shape is svg (required then), relative to the scene file. Remote URLs are not fetched; other shapes do not draw it.

    width requiredxs:positiveInteger

    Width in pixels of the shape's box; an SVG is stretched to fill the box, without keeping its aspect ratio.

    height requiredxs:positiveInteger

    Height in pixels of the shape's box; an SVG is stretched to fill the box, without keeping its aspect ratio.

    fillpaintType#FFFFFFFF

    Fill paint of the shape. Default white. Not used when shape is svg, which draws with the colours inside the file.

    pathxs:string

    SVG path data in the shape's box coordinates; required when shape is path.

    fillRulefillRuleTypeevenodd

    Which regions count as inside for filling: evenodd (default) or nonzero winding. Not used when shape is svg.

    strokepaintType#00000000

    Paint of the outline. Default transparent, so no outline is drawn. Not used when shape is svg.

    strokeWidthnonNegativeDecimal0

    Width in pixels of the outline, centred on the edge; 0 (default) draws none. Not used when shape is svg.

    radiusnonNegativeDecimal0

    Corner radius in pixels of a rect or rounded-rect. Default 0.

    pointsxs:positiveInteger5

    Number of vertices of a polygon (minimum 3) or tips of a star (minimum 2). Default 5.

    innerRadiusnonNegativeDecimal

    For a star, the radius in pixels of the inner vertices from the centre; half the outer radius when absent.

    from attribute group strokeStyle
    strokeCapstrokeCapTypebutt

    Shape of the ends of open stroke segments and dashes: butt (flat, default), round, or square (extends half the stroke width past the end).

    strokeJoinstrokeJoinTypemiter

    Shape of stroke corners: miter (sharp, default), round, or bevel (cut flat).

    miterLimitpositiveDecimal4

    Longest allowed miter, as a ratio of miter length to stroke width; sharper corners are bevelled. Defaults to 4.

    dashnumberListType

    Dash pattern as alternating dash and gap lengths in scene units; an odd count is repeated to make pairs. Absent or all-zero draws a solid stroke.

    dashOffsetxs:double0

    Distance in scene units into the dash pattern at which the outline starts, shifting the dashes along the path. Default 0.

    strokePositionstrokePositionTypecenter

    For a shape: where the stroke sits relative to the outline: center (default), inside (only the part within the shape) or outside (only the part beyond it). Vector assets always stroke centred.

    paintOrderone of fill-stroke stroke-fillfill-stroke

    For a shape: drawing order of fill and stroke: fill-stroke (default) paints the stroke over the fill, stroke-fill paints the fill over the stroke. Vector assets always paint the stroke over the fill.
