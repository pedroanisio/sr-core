    Type of <image> in assetsType

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Name by which layers and other elements (pattern paints, materials, particles, heightmaps) refer to this image.

    src requiredxs:anyURI

    Path of the image file; a remote URL is not fetched when rendering and is reported as an error.

    width requiredxs:positiveInteger

    Width in pixels that layout uses for the image. If the declared width and height differ from a local file's, validation warns, and a different aspect ratio distorts the picture.

    height requiredxs:positiveInteger

    Height in pixels that layout uses for the image. If the declared width and height differ from a local file's, validation warns, and a different aspect ratio distorts the picture.

    colorSpacecolorSpaceTypesrgb

    Colour primaries of the image's pixels, used to convert them to the working space; a usable embedded profile overrides it unless colorProfile is declared. Default srgb.

    transfertransferTypeauto

    Transfer curve that decodes the image's pixel values; auto picks the usual curve for the colour space (linear for linear files). A usable embedded profile overrides it unless colorProfile is declared.

    colorProfilecolorProfileTypeembedded

    Whether a colour profile embedded in the file (embedded, default) overrides colorSpace and transfer, or the declared values always apply (declared); a missing, unusable or raw-space case uses the declared values.

    alphaalphaModeTypeauto

    How the file's alpha channel is read: straight or premultiplied, none to ignore it and treat the image as opaque; auto (default) treats it as straight.

    layerxs:string

    Layer or channel set inside multi-layer files (PSD layer, EXR part).
