    rigidBodyType

    Type of <rigidBody> in layerType, shapeType

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    typeone of static kinematic dynamicdynamic

    static: fixed at its start pose; kinematic: follows its animation and pushes other bodies; dynamic (default): moved by the simulation.

    shapexs:stringbox

    box, circle, capsule, polygon, convex-hull (from alpha) or path.

    pathxs:string

    SVG path data, in the node's own pixels from the top-left of its box, outlining the collider when shape is polygon (convex hull) or path (concave outline). Without it a box is used.

    massxs:double1

    Mass of a dynamic body in kilograms. Default 1.

    frictionunitDecimal0.5

    Surface friction from 0 (frictionless) to 1; against the world bounds the body's own value is used. Default 0.5.

    restitutionunitDecimal0

    Bounciness from 0 (no bounce) to 1 (fully elastic); against the world bounds the body's own value is used. Default 0.

    linearDampingunitDecimal0.01

    Damping that gradually slows the body's linear motion, from 0 (none) to 1. Default 0.01.

    angularDampingunitDecimal0.01

    Damping that gradually slows the body's rotation, from 0 (none) to 1. Default 0.01.

    velocityXxs:double0

    Initial horizontal velocity in pixels per second, positive to the right; applies only to dynamic bodies, when they start to be simulated. Default 0.

    velocityYxs:double0

    Initial vertical velocity in pixels per second, positive downward; applies only to dynamic bodies, when they start to be simulated. Default 0.

    angularVelocityxs:double0

    Initial rotation speed in degrees per second, clockwise on screen; applies only to dynamic bodies, when they start to be simulated. Default 0.

    radiusnonNegativeDecimal0

    Circle collider radius in pixels (scaled with the node); used only when shape is circle. Absent or 0: half the shorter side of the node's box.

    collisionGroupxs:nonNegativeInteger0

    Collision group number of the body, 0 to 31 (larger values act as 31). Default 0.

    collidesWithxs:stringall

    Groups the body collides with: all (default) or group numbers separated by spaces or commas. Two bodies collide only if each lists the other's group.

    sensorxs:booleanfalse

    When true the body is not solid: it exerts no contact forces and others pass through it. Default false.

    fixedRotationxs:booleanfalse

    When true the body cannot rotate, whatever hits it. Default false.

    bulletxs:booleanfalse

    When true the body uses continuous collision detection, so fast motion does not tunnel through thin colliders. Default false.

    activateAtxs:double0

    Time in seconds from which a dynamic body is simulated; before it, the body follows its animation, ignoring gravity, forces and contacts. Default 0.
