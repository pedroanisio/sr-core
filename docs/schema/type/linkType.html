    Drives @property from another value without writing an expression: source is "nodeId.property", "param:name", "audio:trackId[:low|mid|high]" or "marker:id". output = clamp(source * scale + offset, min, max), delayed by @delay seconds and smoothed over @smoothing seconds.

    property requiredxs:string

    Name of the parent element's attribute (or position, scale, anchor, skew on a node) the link drives each frame; an unknown name is an error.

    source requiredxs:string

    Value that drives the property: nodeId.property, param:name, audio:trackId[:low|mid|high|full], or marker:id (0 before the marker, rising to 1 over its duration).

    scalexs:double1

    Multiplier applied to the source value before the offset is added. Default 1.

    offsetxs:double0

    Value added to the scaled source value. Default 0.

    minxs:double

    Lower limit of the output, applied after scale and offset; no limit when absent.

    maxxs:double

    Upper limit of the output, applied after scale and offset; no limit when absent.

    delayxs:double0

    Seconds by which the output lags the source: the property reads the source's value from that long ago. Default 0.

    smoothingnonNegativeDecimal0

    Seconds over which the source is averaged (trailing window) before use; 0 (default) means no smoothing. When set it takes precedence over follow.

    followone of none exponential springnone

    Lag filter applied to the source: none (default), exponential (first-order, see timeConstant) or spring (see stiffness, damping, mass). Ignored when smoothing is set.

    timeConstantpositiveDecimal0.1

    Time constant in seconds of the exponential follow; read only when follow is exponential. Default 0.1.

    stiffnesspositiveDecimal100

    Spring stiffness of the spring follow; read only when follow is spring. Default 100.

    dampingnonNegativeDecimal10

    Spring damping of the spring follow; read only when follow is spring. Default 10.

    masspositiveDecimal1

    Spring mass of the spring follow; read only when follow is spring. Default 1.
