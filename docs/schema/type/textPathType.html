    path requiredxs:string

    SVG path data (any command, absolute or relative) along which the text's glyphs are placed, in the text layer's own pixel space.

    startOffsetlengthType0

    Distance along the path where the text starts, in pixels or as a percentage of the path length; 0 by default. A vw, vh, vmin or vmax value is read as plain pixels. Not used when @forceAlignment is on.

    firstMarginxs:double0

    Pixels added to the starting position of the text on the path; with @forceAlignment it is the inset at the path's start.

    lastMarginxs:double0

    Inset in pixels at the path's end that the text is spread to; used only with @forceAlignment, otherwise it has no effect.

    reversexs:booleanfalse

    When true, the text runs along the path from its end to its start; false by default.

    perpendicularxs:booleantrue

    When true (default), each glyph rotates to follow the path's direction; when false, glyphs keep their orientation.

    forceAlignmentxs:booleanfalse

    When true, the first line of text is stretched or squeezed to fill the path between @firstMargin and @lastMargin, ignoring @startOffset; false by default.
