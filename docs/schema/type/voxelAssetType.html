    voxelAssetType

    Type of <voxelAsset> in assetsType

    Version 1.3 or later (VOX1). A model of cells, each with a palette index 1 to 255: either a file (src, format vox, MagicaVoxel, or srvol, the engine's volume cache with the indices as exact values of the grid voxelGrid) or a closed mesh asset cut into cells (fromMesh and cellSize, the cells whose centres are inside the mesh, on a lattice of multiples of the cell size, by the test that the smoke's colliders use, with the mesh in the frame it is drawn in: scene units, an imported asset in metres being 100 to the metre, and scene axes, so cellSize is in scene units), exactly one of the two (VOX2, VOX3). A vox file with a scene graph is the whole scene, the models placed as the graph says, unless model names one (its number from 0), which is then unplaced. MagicaVoxel's axes (z up) are turned into the scene's (y down, z forward) by a proper rotation. maxCells and maxMemoryMiB bound what is built, before it is allocated, and over either is an error that names the number, never a model cut short. The engine's defaults are 4194304 cells, 128 MiB and the grid voxels; they are not XSD defaults so that the attributes that belong to one source can be refused on the other (VOX2).

    Name by which an object3D's voxels attribute refers to this model.

    srcxs:anyURI

    Path of a local .vox or .srvol file holding the cells; give exactly one of src and fromMesh.

    formatone of vox srvol

    File format of src: vox (MagicaVoxel) or srvol (a volume cache); taken from the file extension when absent. Only allowed with src.

    modelxs:nonNegativeInteger

    Number (from 0) of the one model of a .vox file to use, unplaced; without it a file with a scene graph is used as the whole placed scene, and a file with several models and no graph needs it.

    fromMeshxs:IDREF

    Id of a closed mesh asset to cut into cells: the cells whose centres lie inside the mesh, on a lattice of multiples of cellSize.

    cellSizepositiveDecimal

    Edge length of a cell in scene units, on the mesh as drawn (an imported mesh in metres is 100 per metre); required with fromMesh, not allowed with src. Also the default cell size of an object using the asset.

    voxelGridvolumeChannelType

    Name of the channel of an srvol cache read as the palette indices; voxels when absent. Only for an srvol src.

    maxCellsxs:positiveInteger ≤ 67108864

    Most cells the model may have; a larger one is an error. 4,194,304 when absent.

    maxMemoryMiBxs:positiveInteger ≤ 4096

    Limit in MiB on the size of the source file and on the cells built from it; exceeding either is an error. 128 when absent.

    sha256sha256Type

    SHA-256 digest of the source file, in hex. A local file is hashed when the scene is validated and a different digest is an error; a remote URL is not checked.

    licensexs:string

    Licence of the asset file as free text; copied into the render report's asset credits together with credit, and never checked.

    creditxs:string

    Attribution for the asset file as free text; copied into the render report's asset credits. An asset with neither license nor credit is left out of that list.

    proxyxs:anyURI

    Path of a lighter stand-in file. Rendering with the representation proxy (output/@representation or the --representation option) decodes it instead of src for images, videos, meshes and mixed audio when no representation named proxy exists; it carries no colorSpace, transfer or language of its own. A missing proxy file is warning A01.
