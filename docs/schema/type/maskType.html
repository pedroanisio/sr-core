    maskType

    Type of <mask>
    in 18 typeslayerType, shapeType, connectorType, particleEmitterType, groupType, sequenceType, instanceType, includeType, repeatType, adjustmentType, flockType, fluidType, slimeType, erosionType, viewport3DType, computeType, iterateType, programNodeType

    Masks combine in document order using @mode; the 1.0 behaviour (product of coverages) is mode="intersect", the default. Coverage is anti-aliased, then expanded/contracted by @expansion and blurred by @feather pixels.
