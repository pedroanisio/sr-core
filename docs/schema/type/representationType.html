    representationType

    Type of <representation> in imageAssetType, videoAssetType, audioAssetType

    Alternate encodings of the same media (proxy, high-res, per-language audio, HDR/SDR grade). The renderer picks the representation named by the output's or command line's representation preference, else the asset's own src (OTIO media_references, FCPXML media-rep, AAF EssenceGroup).

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    name requiredxs:NMTOKEN

    Name of this alternate encoding of the asset; it is used when the render requests a representation of that name.

    src requiredxs:anyURI

    Path of the alternate file that replaces the asset's own file when this representation is chosen; a remote URL is not fetched when rendering.
