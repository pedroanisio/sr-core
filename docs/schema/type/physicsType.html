    physicsType

    Type of <physics> in <scene>

    softBody: validation also rejects a body whose stable integration needs more than 4096 substeps per fixedStep. The physics world is metres, +y up; pixelsPerMeter maps it to screen pixels (+y down).

    cachexs:anyURI

    Path to a precomputed physics recording used instead of simulating. A missing file or a mismatching older-format file falls back to simulating; a damaged or non-matching current-format file is an error.

    cacheSha256sha256Type

    SHA-256 of the cache file. A different hash is an error for a current-format cache; for an older-format cache it is reported and the simulation runs instead.

    fixInternalEdgesxs:booleanfalse

    For 3D bodies: fix the contacts that the edges between the triangles of a mesh make. A body that meets a flat mesh gets the mesh's normal whatever its tessellation (without it the normal of the triangle edge or corner the body met, which tilts by several degrees and kicks a sliding body sideways), and a crater from an impact on such a mesh has its axis and speed from the surface either way. The meshes are taken as two-sided. It changes the motion of every body that slides or lands on a mesh, so it is off by default, which is the behaviour there always was.
