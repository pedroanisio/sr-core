    rigidBody3DType

    Type of <rigidBody> in object3DType

    A rigid body in 3D on an object3D: the simulation moves the object from its pose at physics@start (its position and rotations, in its parent's frame); from then on the simulation, not its own attributes, places it (a kinematic body follows its animation). shape="auto" takes the primitive's own form (box, sphere, cylinder, cone, capsule; a plane is a box one unit deep; text is a box) and the convex hull of the triangles of any other primitive; convex-hull, trimesh (exact triangles, for static and kinematic scenery) and decomposition (convex parts of a closed mesh) use the object's triangles. Sizes follow the object's scale at the start. Velocities are pixels per second in scene axes (y down, z away from the camera), angular velocities degrees per second about the scene axes.

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    typeone of static kinematic dynamicdynamic

    static: keeps its start pose; kinematic: follows its animation and pushes other bodies; dynamic (default): moved by the simulation.

    shapeone of auto box sphere capsule cylinder cone convex-hull trimesh decomposition voxelsauto

    Collider: auto uses the primitive's own box, sphere, cylinder, cone or capsule where it fits, else a hull or mesh of its triangles; other values force that form (trimesh: static or kinematic only; voxels: the cells).

    masspositiveDecimal1

    Total mass of the body in kilograms; default 1. A body of cells takes its mass from density instead.

    densitypositiveDecimal

    Kilograms per cubic metre, for a body of cells (VOX9, VOX10): its mass is the number of cells times the volume of one (cellSize times the object's scale, over the scene's pixelsPerMeter, cubed) times this. Required with cells as the collider, and mass is then not given.

    maxFragmentsxs:positiveInteger ≤ 4096

    A body of cells that a crater or a fracture can break gets this many slots (bodies that wait, one cell each, until a cut frees a part of it): 1 to 4096; the engine's value is 64, and it is not an XSD default so that it can be refused where there is nothing to cut (VOX11). The world refuses more fragments than slots (see fragmentOverflow).

    fragmentMinCellsxs:positiveInteger

    Loose parts of a cut with fewer cells than this are dust: they leave the body and become particles (VOX11). The engine's value is 1.

    fragmentOverflowone of error dust

    What a cut does when it frees more parts than there are slots (VOX11): error names both numbers, dust makes the smallest parts dust. The engine's value is error.

    anchorone of largest base

    Which part of what a crater's cut leaves stays the body (VOX12): base, every part that touches the base layer (the cells of the greatest y key, the lowest layer in the scene's axes, y down), the way ground is held by what is under it, or largest, the largest connected part. Only an owner with a crater has it, and that owner is static or kinematic (CRT5), so the engine's value when it is not given is base: a dynamic body, whose cut would leave its largest part, has no anchor to give.

    frictionunitDecimal0.5

    Surface friction from 0 (frictionless) to 1; between two bodies the average of their values is used. Default 0.5.

    restitutionunitDecimal0

    Bounciness from 0 (no bounce) to 1; between two bodies the average of their values is used. Default 0.

    linearDampingunitDecimal0.01

    Linear damping coefficient in 1/s (0 to 1): each step divides the linear velocity by 1 plus this value times the step length. Default 0.01.

    angularDampingunitDecimal0.01

    Angular damping coefficient in 1/s (0 to 1): each step divides the angular velocity by 1 plus this value times the step length. Default 0.01.

    velocityXxs:double0

    Initial horizontal velocity in pixels per second (scene axes), positive to the right; applies only to dynamic bodies, when they start to be simulated. Default 0.

    velocityYxs:double0

    Initial vertical velocity in pixels per second (scene axes), positive downward; applies only to dynamic bodies, when they start to be simulated. Default 0.

    velocityZxs:double0

    Initial depth velocity in pixels per second (scene axes), positive away from the camera; applies only to dynamic bodies, when they start to be simulated. Default 0.

    angularVelocityXxs:double0

    Initial rotation speed about the scene x axis in degrees per second; applies only to dynamic bodies, when they start to be simulated. Default 0.

    angularVelocityYxs:double0

    Initial rotation speed about the scene y axis in degrees per second; applies only to dynamic bodies, when they start to be simulated. Default 0.

    angularVelocityZxs:double0

    Initial rotation speed about the scene z axis in degrees per second; applies only to dynamic bodies, when they start to be simulated. Default 0.

    collisionGroupxs:nonNegativeInteger0

    Collision group number of the body, 0 to 31 (larger values act as 31). Default 0.

    collidesWithxs:stringall

    Groups the body collides with: all (default) or group numbers separated by spaces or commas. Two bodies collide only if each lists the other's group.

    sensorxs:booleanfalse

    When true the body is not solid: it exerts no contact forces and others pass through it. Default false.

    fixedRotationxs:booleanfalse

    When true the body cannot rotate, whatever hits it. Default false.

    bulletxs:booleanfalse

    When true the body uses continuous collision detection, so fast motion does not tunnel through thin colliders. Default false.

    activateAtxs:double0

    Time in seconds from which a dynamic body is simulated; before it, the body follows its animation, ignoring gravity, forces and contacts. Default 0.
