    outputType

    Type of <output> in <scene>

    Several outputs render one scene into different placements. layout picks a layoutVariant frame; variant picks a parameter set; start/end render a range. Width/height default to the layout's, else the project's. Sequence codecs write numbered files at @path (printf pattern).

    Content

    • one ofany number
      • <poster>
      • <thumbnail>
      • <destination>
      • <segment>
      • <audioTrack>
      • <captionTrack>

    idxs:ID

    Name by which the command line selects this output; it also fills {id} in a report path given on the command line.

    audioTracksxs:IDREFS

    Ids of the audioTrack elements whose sound is mixed into this output; combined with audioRoles and audioBuses as a union, and all sources play when none of the three is given. Only outputs with segments use it.

    audioRolesaudioRoleListType

    Roles (such as dialogue or music) of the audio tracks whose sound is mixed into this output; combined with audioTracks and audioBuses as a union. Only outputs with segments use it.

    audioBusesxs:IDREFS

    Ids of the buses whose tracks are mixed into this output; combined with audioTracks and audioRoles as a union. Only outputs with segments use it.

    overlayxs:IDREF

    A symbol drawn over the output's picture in output time (series tags, calls to action, end cards).

    joinFadenonNegativeDecimal0.01

    Length in seconds of the audio crossfade centred on a join between two segments that has no transition; never longer than either segment. 0.01 when absent.

    path requiredxs:anyURI

    File the output is written to; a relative path is resolved against the output directory (default the document's folder). Sequence codecs need a printf pattern such as frame_%05d.png.

    codec required

    Format the output is encoded in: a video codec (h264, h265, av1, vp9, ffv1, prores, dnxhr), an animated image (gif, apng, webp), an image sequence (png-sequence, jpeg-sequence, exr-sequence, tiff-sequence) or audio-only.

    containerone of mp4 mov mkv webm mxf wav m4a mp3

    File container: mp4, mov, mkv, webm, mxf, wav, m4a or mp3; from the path's extension, else the codec's default. A container that cannot hold a video codec is rejected; wav, m4a and mp3 hold only audio-only.

    Width in pixels of the delivered frame; defaults to the 360 frame, the layout's frame or the project's.

    heightxs:positiveInteger

    Height in pixels of the delivered frame; defaults to the 360 frame, the layout's frame or the project's.

    fpsfpsType

    Frame rate of the output, an integer or a fraction; the project's frame rate when absent.

    layoutxs:IDREF

    Id of the layout whose frame and reframing this output uses.

    variantxs:IDREF

    Id of the parameter variant applied when rendering this output.

    startxs:double0

    Time in seconds where the rendered range begins; 0 when absent. An output with segments cannot set a non-zero start; the range goes in a segment instead.

    endxs:double

    Time in seconds where the rendered range ends; the end of the timeline when absent. Must be greater than start, and not allowed on an output with segments.

    pixelFormatxs:stringyuv420p

    Pixel format passed to h264, h265, av1, and to vp9 and ffv1 without alpha (yuv420p by default); for dnxhr and png/apng a 10, 12 or 16 in the name selects deep colour; other codecs choose their own.

    presetxs:stringmedium

    Encoder speed preset (such as medium or slow) used by h264, h265, av1 and vp9; medium when absent.

    profilexs:string

    Encoder profile name passed to the encoder (such as high); for dnxhr it selects the DNxHR profile, and prores uses proresProfile instead. The encoder's own choice when absent.

    levelxs:string

    Encoder level passed to the encoder (such as 4.1); the encoder's own choice when absent.

    proresProfileone of proxy lt 422 hq 4444 4444xq

    ProRes profile (proxy, lt, 422, hq, 4444, 4444xq); hq when absent, or 4444 with alpha. Read only for prores.

    crfxs:nonNegativeInteger18

    Constant-quality value of the lossy video encoders, lower meaning higher quality; 18 when absent. Most encoders use bitrate instead when one is set; some convert crf to their own quality scale.

    bitratexs:positiveInteger

    Target video bitrate in bits per second; for most encoders it replaces the constant-quality crf. A maxFileSize overrides it with a bitrate derived from the file size.

    maxBitratexs:positiveInteger

    Upper bitrate limit in bits per second, passed to the video encoder as its maximum rate. Not used for prores, dnxhr, ffv1 or image outputs, nor by some AV1 and hardware encoders.

    bufferSizexs:positiveInteger

    Rate-control buffer size in bits, passed to the video encoder as its buffer size. Not used for prores, dnxhr, ffv1 or image outputs, nor by some AV1 and hardware encoders.

    twoPassxs:booleanfalse

    When true, encodes in two passes; the first gathers statistics for rate control, which only software h264, h265 and vp9 encoders and most av1 encoders use. A maxFileSize also forces two passes; false when absent.

    keyframeIntervalpositiveDecimal2

    Distance between keyframes in seconds (times the frame rate, at least 1 frame, gives the GOP length); 2 when absent. Used by h264, h265, av1 and vp9; prores, dnxhr, ffv1 and image outputs ignore it.

    bFramesxs:nonNegativeInteger

    Maximum consecutive B-frames; applied to h264 and h265 only, the encoder's own choice when absent.

    faststartxs:booleantrue

    When true, MP4, MOV and M4A files are written with their index at the front so playback can start before the download ends; true when absent.

    alphaxs:booleanfalse

    When true, the output keeps transparency; only prores, vp9, ffv1, png, exr, tiff, apng, webp and gif outputs can carry it, and any other codec is rejected. false when absent.

    audioCodecxs:stringaac

    Audio codec for the audio stream (aac by default); a webm container uses opus in place of aac. An audio-only output reads it only for the m4a container.

    audioBitratexs:positiveInteger192000

    Bitrate of the compressed audio stream in bits per second; 192000 when absent.

    audioxs:booleantrue

    Whether the output carries the scene's audio; with false a video file has no audio track, and an audio-only output is then an error. true when absent.

    colorSpacecolorSpaceTypesrgb

    Colour space (primaries) the frames are converted to; srgb when absent. Exr sequences use linear-srgb in its place.

    transfertransferTypeauto

    Transfer function (gamma curve) of the encoded frames; auto picks it from the colour space. Exr sequences are always linear.

    colorRangeone of limited fulllimited

    Whether encoded YUV values use the limited (studio) or full range; limited when absent. Image outputs are always full range.

    maxCLLxs:nonNegativeInteger

    Maximum content light level in nits written as HDR metadata by the x265 and SVT-AV1 encoders.

    maxFALLxs:nonNegativeInteger

    Maximum frame-average light level in nits written as HDR metadata by x265, or by SVT-AV1 only when maxCLL is also set.

    masteringDisplayxs:string

    Mastering display colour volume as the x265 or SVT-AV1 encoder expects it, written as HDR metadata.

    sphericalMetadataxs:booleantrue

    When true, MP4 and MOV outputs of a scene360 scene get spherical-video metadata so players treat them as 360; true when absent. Written for equirectangular and cubemap layouts only.

    captionsxs:IDREFS

    Ids of caption tracks written as sidecar subtitle files next to this output, in addition to every track whose mode is not burn.

    burnCaptionsxs:IDREF

    Id of the one caption track burned into this output's picture; without it, every track whose mode is not sidecar is burned.

    loopCountxs:nonNegativeInteger0

    GIF/APNG/WebP loop count; 0 = infinite.

    maxFileSizexs:positiveInteger

    Bytes; the encoder picks a bitrate that fits (platform upload limits).

    embedMetadataxs:booleantrue

    When true, the metadata element's title, author, description, copyright and keywords are written into the file; true when absent.

    representationxs:NMTOKEN

    Preferred asset representation name for this output (e.g. "proxy" for drafts).

    reportxs:anyURI

    Where to write this output's render report (scene-render-report/1), relative to the document.
