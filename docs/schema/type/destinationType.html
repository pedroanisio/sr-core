    destinationType

    Type of <destination> in outputType

    Post-render delivery. Credentials are never stored in the document: @credentials names an environment profile.

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    kind requiredone of file s3 gcs azure-blob http-put sftp webhook

    How the rendered files are delivered: file (copy), s3, gcs, azure-blob, http-put, sftp, or webhook, which is notified with the resulting locations.

    uri requiredxs:anyURI

    Where the files go: a directory for file, a bucket and prefix URL for s3 and similar kinds, or the endpoint for http-put and webhook.

    credentialsxs:NMTOKEN

    Name of a credentials profile read from SR_CREDENTIALS_<PROFILE>_<NAME> environment variables; no secrets are stored in the document.
