    pointsType

    Type of <points> in repeatType

    Generates the points on which a repeat places its copies: one copy per point, copy i on point i, in the repeat's own space (pixels, +y down). type grid (columns x rows, centred on the origin), along-path (count points at equal arc length along @path), scatter (count seeded points inside width x height centred on the origin, or inside @path), vertices (one point per vertex of @path) or list (the pairs of @at). Expressions inside the repeat read pointX, pointY, pointAngle, pointU and pointRandom.

    Where the points go: grid, along-path (needs path and count), scatter (needs count and a path, or width and height), vertices (needs path) or list (needs at). Required.

    columnsxs:positiveInteger1

    Number of columns of a grid of points, centred on the origin; default 1.

    rowsxs:positiveInteger1

    Number of rows of a grid of points, centred on the origin; default 1.

    spacingXxs:double100

    Horizontal distance in pixels between grid columns; default 100. It can be animated.

    spacingYxs:double100

    Vertical distance in pixels between grid rows; default 100. It can be animated.

    countxs:nonNegativeInteger

    Number of points for along-path; for scatter, the most points made (fewer if too few candidates land inside a path). Absent counts as 0.

    pathxs:string

    Path data used by along-path, vertices, and by scatter to confine points inside the path; with scatter it excludes width and height.

    fillRulefillRuleTypenonzero

    Fill rule deciding which area counts as inside the path for scatter: nonzero (default) or evenodd.

    orientxs:booleanfalse

    When true, along-path copies are rotated to the path direction at their point; default false.

    widthnonNegativeDecimal

    Width in pixels of the rectangle, centred on the origin, that scatter fills; required with height for scatter without a path, not allowed with a path; it can be animated.

    heightnonNegativeDecimal

    Height in pixels of the rectangle, centred on the origin, that scatter fills; required with width for scatter without a path, not allowed with a path; it can be animated.

    atpointListType

    Explicit list of x,y pairs, in pixels, for type list.

    seedxs:unsignedLong

    Seed of the random scatter; absent, the project seed is used.
