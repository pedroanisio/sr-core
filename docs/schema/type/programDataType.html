    programDataType

    Type of <program> in parametersType

    Runs the module once; the JSON rows it returns are a data source for repeat/@over.

    Content

      1. <param>any number

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Unique name of the data source; a repeat refers to it by this id to iterate over the rows the module returns.

    from attribute group programAttributes
    src requiredxs:anyURI

    Location of the WebAssembly module to run; it must be a local file, and a remote URI is refused.

    sha256 requiredsha256Type

    Lowercase hex SHA-256 of the module's bytes; the module is not run, and the render fails, if the file does not match.

    seedxs:unsignedLong0

    Seed, combined with the project seed, of the module's random number generator; the same seeds give the same output. Default 0.

    fuelxs:unsignedLong in [1, 1000000000000]1000000000

    Instructions a call of the module may execute (SREP 66, Determinism 4).

    memoryLimitxs:positiveInteger ≤ 409664

    MiB of linear memory the module may hold (a multiple of 64 KiB pages: 16 pages per MiB).

    outputSha256sha256Type

    SHA-256 of the output that a build or data program returns; the render fails if the output hashes differently, which pins the result across hosts.
