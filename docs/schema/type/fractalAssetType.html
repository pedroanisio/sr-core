    fractalAssetType

    Type of <fractal> in assetsType

    Escape-time fractal image of width x height pixels. Each pixel shows the escape count of its centre in exact arithmetic (up to 2^-20 of a pixel; SREP 75), whatever the zoom.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Unique identifier that layers use to show this fractal image.

    kind requiredone of mandelbrot julia

    Which set is drawn: the Mandelbrot set, or the Julia set of the constant given by juliaX and juliaY, which julia requires and mandelbrot does not allow.

    width requiredxs:positiveInteger

    Width of the fractal image in pixels; every pixel is computed individually, without anti-aliasing.

    height requiredxs:positiveInteger

    Height of the fractal image in pixels; every pixel is computed individually, without anti-aliasing.

    centerXxs:decimal0

    Real part of the point at the centre of the image, an exact decimal read at full length whatever its number of digits. Default 0.

    centerYxs:decimal0

    Imaginary part of the point at the centre of the image, an exact decimal read at full length whatever its number of digits. Default 0.

    juliaXxs:decimal

    Real part of the Julia constant. Required together with juliaY for kind julia; a mandelbrot must not have both.

    juliaYxs:decimal

    Imaginary part of the Julia constant. Required together with juliaX for kind julia; a mandelbrot must not have both.

    spanpositiveDecimal4

    Width of the view in the complex plane at zoom 0, so one pixel covers span divided by the image width; larger values show more. Default 4.

    zoomxs:double0

    Magnification as a power of ten: the view is 10 to the zoom times narrower than span, so 2 shows a hundredth of the width. Can be animated; default 0.

    rotationxs:double0

    Turns the picture about its centre by this many degrees, counterclockwise on screen (the sampling grid turns clockwise). Default 0.

    maxIterationsxs:positiveInteger ≤ 1000000001000

    Iteration limit per pixel, 1 to 100,000,000; points that have not escaped by then count as inside and take insideColor. Default 1000.

    bailoutpositiveDecimal2

    Escape radius: a pixel escapes at the first iteration where the orbit's distance from the origin exceeds it. Default 2; smooth colouring is measured against it.

    colorModeone of bands smoothsmooth

    bands picks a palette colour by the escape count; smooth interpolates between neighbouring palette colours using a fractional count. Default smooth.

    palettexs:string#000764FF #206BCBFF #EDFFFFFF #FFAA00FF #000200FF

    Space-separated list of colours cycled through by escape count; a token that is not a colour is an error. Default: dark blue, blue, white, orange and near black.

    paletteScalepositiveDecimal0.05

    Smooth mode only: palette steps per escape iteration, so 0.05 moves one colour along every 20 iterations. Default 0.05.

    paletteOffsetxs:double0

    Smooth mode only: shift added to the scaled palette position, where 1 moves one colour along the palette. Default 0.

    insideColorcolorType#000000FF

    Colour of the points that never escape. Default opaque black.
