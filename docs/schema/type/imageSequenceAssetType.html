    imageSequenceAssetType

    Type of <imageSequence> in assetsType

    Numbered frames, src uses printf padding ("logo_%04d.png") or ####.

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Name by which layers refer to this image sequence.

    src requiredxs:string

    Pattern of the numbered frame files, with printf padding such as logo_%04d.png or # characters for the digits.

    first requiredxs:integer

    Number of the first frame file.

    last requiredxs:integer

    Upper limit of the frame file numbers; frames run from first in steps of step up to the last number not above this. It must not precede first.

    stepxs:positiveInteger1

    Increment between consecutive frame file numbers. Default 1.

    fps requiredfpsType

    Playback rate of the sequence in frames per second (integer or fraction); sets how fast it advances through the files.

    width requiredxs:positiveInteger

    Width in pixels that layout uses for the sequence frames.

    height requiredxs:positiveInteger

    Height in pixels that layout uses for the sequence frames.

    colorSpacecolorSpaceTypesrgb

    Colour primaries of the frames, used to convert them to the working space. A profile embedded in a frame file overrides it unless colorProfile is declared. Default srgb.

    transfertransferTypeauto

    Transfer curve that decodes the frame values; auto picks the usual curve for the colour space. A profile embedded in a frame file overrides it unless colorProfile is declared.

    colorProfilecolorProfileTypeembedded

    embedded (default): a profile or colour code points in the frame file take precedence over colorSpace and transfer, unless colorSpace is raw; declared: colorSpace and transfer always apply.

    alphaalphaModeTypeauto

    How the file's alpha channel is read: straight or premultiplied, none to ignore it and treat the image as opaque; auto (default) treats it as straight.

    missingFrameone of error hold black transparenterror

    What a missing frame file shows: error (default) reports it, hold repeats the nearest earlier frame (nothing if none exists), black shows black, transparent shows nothing.

    from attribute group assetProvenance

    SHA-256 digest of the source file, in hex. A local file is hashed when the scene is validated and a different digest is an error; a remote URL is not checked.
