    pdfRegionType

    Type of <region> in pdfAssetType

    A box on the page, in the cache image's pixels (origin top-left, +y down). With @text, the resolve step finds the occurrence-th match of the phrase in the page's text and writes x, y, width and height; without it, the box is given by hand.

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Identifier that shapes name in region to be placed on this box.

    textxs:string

    Phrase whose position the resolve step finds on the page; the match is case-sensitive, and whitespace, soft hyphens and line-end hyphens are normalised. Without it the box is given by hand.

    occurrencexs:positiveInteger1

    Which match of the phrase to use, counting from 1 from the start of the page's text; matches do not overlap and 1 is the default.

    xxs:double

    Left edge of the box in pixels of the page's cache image, measured from its left edge; written by the resolve step when text is set and optional until then; without text, all four box attributes are required (C81).

    yxs:double

    Top edge of the box in pixels of the page's cache image, measured downward from its top; written by the resolve step when text is set and optional until then; without text, all four box attributes are required (C81).

    widthnonNegativeDecimal

    Width of the box in pixels of the page's cache image; written by the resolve step when text is set and optional until then; without text, all four box attributes are required (C81).

    heightnonNegativeDecimal

    Height of the box in pixels of the page's cache image; written by the resolve step when text is set and optional until then; without text, all four box attributes are required (C81).
