    Type of <shapeModifier> in shapeType

    Procedural path operators applied in document order (Lottie/After Effects shape modifiers): repeater, offset-path, pucker-bloat, zig-zag, twist, round-corners, wiggle-path, merge (mode), trim (sequential across paths).

    type requiredone of repeater offset-path pucker-bloat zig-zag twist round-corners wiggle-path merge trim

    The procedural operator applied to the shape's outline: repeater, offset-path, pucker-bloat, zig-zag, twist, round-corners, wiggle-path, merge or trim. Modifiers apply in document order.

    copiesxs:double3

    Number of copies a repeater draws, rounded down (default 3). Values above 10 000 are rejected.

    offsetxs:double0

    Repeater: shifts the copy index at which the per-copy transform starts. Trim: rotates the trimmed section along the outline, in degrees (360 = one full length).

    amountxs:double0

    Strength of the operator: offset-path distance in pixels, pucker-bloat in percent, twist in degrees at the farthest point, round-corners radius in pixels, trim in percent cut from the end.

    sizexs:double10

    Wiggle-path: peak displacement of the points; zig-zag: distance every other point is offset from the path. Both in pixels, default 10.

    ridgesxs:nonNegativeInteger5

    Zig-zag: number of ridges per path segment (default 5), limited to 1-1024.

    frequencyxs:double2

    Wiggle-path: how fast the displacement changes, in noise steps per second (default 2).

    detailxs:double10

    Wiggle-path: number of points added per 100 pixels of outline length (default 10), at least 3 per outline.

    seedxs:unsignedLong

    Wiggle-path: seed of the random displacement; 0 when absent.

    modexs:NMTOKEN

    merge: add|subtract|intersect|exclude; zig-zag and wiggle-path: corner|smooth (wiggle-path smooth joins the wiggled points with a Catmull-Rom spline through them instead of straight lines); offset-path join: miter|round|bevel.

    offsetXxs:double0

    Repeater: horizontal shift in pixels applied cumulatively per copy (default 0).

    offsetYxs:double0

    Repeater: vertical shift in pixels applied cumulatively per copy (default 0).

    rotationxs:double0

    Repeater: rotation in degrees applied cumulatively per copy, about the shape's centre (default 0).

    scalexs:double1

    Repeater: scale factor applied cumulatively per copy about the shape's centre (default 1; each copy is scaled by this factor to the power of its index).

    startOpacityunitDecimal1

    Repeater: opacity 0-1 of the first copy (default 1); opacity changes linearly to @endOpacity at the last copy.

    endOpacityunitDecimal1

    Repeater: opacity 0-1 of the last copy (default 1), reached linearly from @startOpacity.

    compositeone of above belowabove

    Repeater: whether later copies are drawn above (default) or below earlier ones.
