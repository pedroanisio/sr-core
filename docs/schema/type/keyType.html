    keyType

    Type of <key> in animateType, timeRemapType

    value is parsed with the type of the animated property (number, "x,y", colour, paint, path data, string). easeIn/easeOut are After Effects-style temporal handles "influence,speed" normalised to [0,1]; spatialIn/Out are motion-path tangents in pixels relative to the key value.

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    time requiredxs:double

    Time of the key in seconds on the animation's time base (see timeBase); with a marker, an offset from it. Times must not decrease.

    value requiredxs:string

    The value at the key, written in the form of the animated property (number, x,y pair, colour, path data, string); keys of one animation must not mix units or shapes.

    interpolationcurveType

    Curve used for the segment from this key to the next; keys without one take the animation's defaultInterpolation.

    bezierxs:string

    Control points x1,y1,x2,y2 of a cubic Bezier as in CSS easing, x1 and x2 in 0-1; used for a cubic-bezier segment, over easeIn and easeOut. A key set to cubic-bezier needs it or a handle.

    easeInpointType

    Handle "influence,speed" (as in keyframe editors) where the previous segment arrives at this key; with the previous key's easeOut it shapes a cubic-bezier segment that has no bezier.

    easeOutpointType

    Handle "influence,speed" (as in keyframe editors) leaving this key; it shapes the cubic-bezier segment to the next key when no bezier is given (default influence 1/3, speed 1).

    spatialInpointType

    Tangent of a motion path arriving at this key, in pixels relative to the key's position; with the previous key's spatialOut it bends the path between two pixel positions.

    spatialOutpointType

    Tangent of a motion path leaving this key, in pixels relative to the key's position; with the next key's spatialIn it bends the path between two pixel positions.

    rovingxs:booleanfalse

    If true, the key's time is recomputed between the nearest non-roving keys in proportion to the distance travelled in value, giving constant speed on linear segments; first and last keys never rove. Default false.

    carryxs:booleanfalse

    On a key whose segment is a spring: start the spring with the velocity the previous segment arrives at this key with (its rate of change at the end), instead of from rest, so a hit that follows another keeps its momentum. Needs a previous key and a following key.

    stepsxs:positiveInteger

    Number of jumps of a steps segment from this key to the next; 1 when absent. A key whose interpolation is steps must set it.

    stepPositionone of start endend

    For a steps segment, whether each jump happens at the start of its interval (start) or at the end (end, default).

    tensionsignedUnitDecimal0

    Kochanek-Bartels tension of the tcb spline at this key, from -1 to 1; the tangent is scaled by (1 - tension), so 0 is the default and 1 flattens the tangent.

    continuitysignedUnitDecimal0

    Kochanek-Bartels continuity of the tcb spline at this key, from -1 to 1; 0 (default) gives a smooth tangent, other values weight the incoming and outgoing directions differently.

    biassignedUnitDecimal0

    Kochanek-Bartels bias of the tcb spline at this key, from -1 to 1; 0 (default) is even, other values weight the tangent toward the previous or next key.

    stiffnesspositiveDecimal100

    Spring stiffness of a spring segment from this key; larger values make it oscillate faster. Default 100.

    dampingnonNegativeDecimal10

    Spring damping of a spring segment from this key; larger values make it settle with less overshoot. Default 10.

    masspositiveDecimal1

    Mass of the spring segment from this key; larger values make it respond more slowly. Default 1.

    overshootnonNegativeDecimal

    The constant of a back-in, back-out or back-in-out segment (default 1.70158, about 10 % overshoot; 0 is the plain cubic). Read from the key the segment leaves.

    periodpositiveDecimal

    The ringing period of an elastic-in, elastic-out or elastic-in-out segment as a fraction of the segment (default 0.3; 0.45 for elastic-in-out). Read from the key the segment leaves.

    markerxs:NCName

    Snap the key time to a marker; @time becomes an offset from it. A marker of the scene, or a beat.N or bar.N id generated by its beatGrid.
