    materialType

    Type of <material> in materialsType

    glTF 2.0 metallic-roughness plus the ratified KHR_materials_* extensions (clearcoat, transmission, ior, sheen, volume, specular, iridescence, anisotropy, dispersion, emissive_strength, unlit). @materialX points to a MaterialX/OpenPBR document that replaces these parameters when present.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Identifier of the material; nodes select it with @material.

    baseColorcolorType#FFFFFFFF

    Base color of the surface. Its alpha is the opacity under alphaMode blend and is tested against alphaCutoff under mask. A base color map multiplies it. Default opaque white.

    metallicunitDecimal0

    Metalness from 0 (dielectric) to 1 (metal); the blue channel of the metallic-roughness map multiplies it. Default 0. A loaded materialX document replaces it.

    roughnessunitDecimal0.5

    Surface roughness from 0 (mirror-like) to 1 (fully diffuse highlights); the green channel of the metallic-roughness map multiplies it. Default 0.5. A loaded materialX document replaces it.

    emissivecolorType#000000FF

    Color of light the surface gives off regardless of lighting; an emissive map multiplies it. Default black (no emission). A loaded materialX document replaces it when drawing.

    emissiveStrengthnonNegativeDecimal1

    Multiplier on the emissive color, which can exceed 1 for a brighter glow. Default 1. A loaded materialX document replaces it when drawing.

    opacityunitDecimal1

    Opacity from 0 to 1, multiplied with the base color alpha to give the surface alpha that alphaMode mask or blend uses. Default 1.

    alphaModeone of opaque mask blendopaque

    How alpha is used: mask discards pixels whose alpha is below alphaCutoff, blend composites the surface with its alpha, opaque does neither (a node opacity below 1 still fades it). Default opaque.

    alphaCutoffunitDecimal0.5

    Alpha threshold from 0 to 1 for alphaMode mask: pixels with alpha below it are discarded. Default 0.5; unused in other modes. A loaded materialX document replaces it.

    doubleSidedxs:booleanfalse

    In the rasterized renderer, when true back faces are drawn too, shaded with the flipped normal; when false they are culled. Default false. The path-traced renderer does not apply it.

    unlitxs:booleanfalse

    When true, the surface shows its base color without any lighting or shading. Default false. A loaded materialX document replaces it when drawing.

    clearcoatunitDecimal0

    Strength from 0 to 1 of a glossy clear layer over the surface. Default 0 (none). Not applied by the path tracer.

    clearcoatRoughnessunitDecimal0

    Roughness from 0 to 1 of the clear-coat layer; used only when clearcoat is above 0. Default 0. Not applied by the path tracer.

    transmissionunitDecimal0

    Share from 0 to 1 of light that passes through the surface, showing a refracted view of what is behind. Default 0.

    iorpositiveDecimal1.5

    Index of refraction: sets how strongly dielectrics reflect and how much transmitted light bends; values below 1 count as 1. Default 1.5. A loaded materialX document replaces it.

    thicknessnonNegativeDecimal0

    Thickness of the transmissive volume: the world-space distance the refracted ray travels inside before the scene behind is sampled. Default 0. Not applied by the path tracer.

    attenuationColorcolorType#FFFFFFFF

    Color that light has after travelling attenuationDistance through a transmissive volume. Default white (no tint); has no effect without attenuationDistance.

    attenuationDistancepositiveDecimal

    Distance, in world units, over which light travelling through a transmissive volume is tinted to attenuationColor; longer paths through the volume tint more. When absent there is no attenuation.

    sheenColorcolorType#000000FF

    Color of the soft sheen seen at grazing angles, as on cloth. Default black (no sheen). Not applied by the path tracer.

    sheenRoughnessunitDecimal0

    Roughness from 0 to 1 of the sheen lobe. Default 0. Not applied by the path tracer.

    specularunitDecimal1

    Strength from 0 to 1 of the specular reflection of non-metal surfaces; metals are unaffected. Default 1. A loaded materialX document replaces it.

    specularColorcolorType#FFFFFFFF

    Tint of the specular reflection of non-metal surfaces; the path tracer uses only its brightness. Default white (untinted).

    iridescenceunitDecimal0

    Strength from 0 to 1 of a thin-film rainbow shift in the reflection. Default 0 (none). Not applied by the path tracer.

    iridescenceIorpositiveDecimal1.3

    Index of refraction of the thin iridescent film. Default 1.3; used only when iridescence is above 0. Not applied by the path tracer.

    anisotropysignedUnitDecimal0

    Strength of stretched, direction-dependent highlights, from -1 to 1; 0 gives ordinary isotropic highlights. Default 0. Not applied by the path tracer.

    anisotropyRotationxs:double0

    Rotation of the anisotropic stretch direction in the surface's tangent plane, in degrees; used only when anisotropy is not 0. Default 0. Not applied by the path tracer.

    dispersionnonNegativeDecimal0

    Strength of color separation in refraction for transmissive surfaces; 0 is none, larger values spread red and blue further. Default 0. Not applied by the path tracer.

    baseColorMapxs:anyURI

    Texture, by file URI or by #id of an image or generator asset, that multiplies the base color; read as sRGB color. No map when absent.

    normalMapxs:anyURI

    Tangent-space normal map, by file URI or #id of an image or generator asset, that perturbs the shading normal; read as linear data. No map when absent.

    normalScalexs:double1

    Multiplier on the x and y components of the normal map's tilt: 1 is as authored, 0 flattens it. Default 1. A loaded materialX document replaces it.

    metallicRoughnessMapxs:anyURI

    Texture, by file URI or #id, whose green channel multiplies roughness and blue channel multiplies metallic; read as linear data. No map when absent.

    occlusionMapxs:anyURI

    Texture, by file URI or #id, whose red channel darkens ambient and environment lighting (not direct lights) where it is dark; read as linear data. No map when absent.

    emissiveMapxs:anyURI

    Texture, by file URI or #id, that multiplies the emissive color; read as sRGB color. No map when absent.

    displacementMapxs:anyURI

    Texture, by file URI or #id, whose red channel moves vertices along their normals by displacementScale; read as linear data. No map when absent.

    displacementScalexs:double0

    Distance, in the mesh's own model units, that a displacement map value of 1 moves a vertex along its normal. Default 0 (no displacement). A loaded materialX document replaces it.

    uvScaleXxs:double1

    Multiplier on the horizontal (U) texture coordinate of all the material's maps. Default 1.

    uvScaleYxs:double1

    Multiplier on the vertical (V) texture coordinate of all the material's maps. Default 1.

    unevennessunitDecimal0

    Amount of procedural surface unevenness: a smooth noise fixed to the object that tilts the shading normal and varies the roughness, for a hand-made (clay) look. 0 is off.

    unevennessScalepositiveDecimal8

    Size of the largest features of the unevenness, in scene units (pixels at the object's scale).

    unevennessSeedxs:nonNegativeInteger0

    Integer seed of the unevenness noise; different seeds give different patterns. No effect while unevenness is 0, and the path-traced renderer does not apply unevenness.

    subsurfaceunitDecimal0

    Weight from 0 to 1 of light scattering beneath the surface in the diffuse shading, softening the light terminator for a waxy or skin look. Default 0 (off). A loaded materialX document replaces it.

    subsurfaceColorcolorType#CCCCCCFF

    Color of the light scattered beneath the surface (its scattering albedo). Default #CCCCCC; used when subsurface is above 0. A loaded materialX document replaces it.

    subsurfaceRadiusnonNegativeDecimal10

    Mean free path in scene units (pixels), multiplied per channel by subsurfaceRadiusScale.

    subsurfaceRadiusScaleunitTripleType1 0.5 0.25

    Three factors from 0 to 1 that scale the subsurface radius for red, green and blue, so colors spread differently. Default 1 0.5 0.25. A loaded materialX document replaces it.

    materialXxs:anyURI

    URI of a MaterialX document whose parameters replace this material's own; uvScale and doubleSided are kept, as are maps the document does not supply. An unreadable document is reported as an error.
