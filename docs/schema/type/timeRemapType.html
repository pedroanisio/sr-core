    timeRemapType

    Type of <timeRemap> in layerType, instanceType, segmentType

    Maps layer-local time (key/@time) to source time (key/@value, seconds). Replaces speed/reverse/loop when present; speed ramps, freezes and reversals are expressed as keys.

    Curve for time-remap key segments that have no interpolation of their own. Default linear.

    frameBlendone of none frame-mix optical-flownone

    How video frames are blended when the remapped source time falls between two frames: none (default), frame-mix (cross-fade) or optical-flow (along motion). A layer's own frameBlend other than none takes precedence.
