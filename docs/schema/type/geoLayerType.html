    geoLayerType

    Type of <geoLayer> in mapAssetType

    The features of a geo asset: polygons filled and stroked, lines stroked (drawn on by @progress), points as dots. @filter keeps features whose property equals (prop=value) or differs from (prop!=value) a value. Choropleth: @fillBy names a numeric property mapped through @domain (data range by default) and @scale onto @palette (colours interpolated in sRGB; quantize picks one colour per equal step); features without a value use @noData. @label names a property drawn at each feature's centre.
