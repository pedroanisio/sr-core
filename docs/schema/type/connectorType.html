    connectorType

    Type of <connector> in groupType, sequenceType, repeatType, iterateType, compositionType, symbolType

    A line between two nodes (or fixed points) that is recomputed every frame, so it stays attached while they move. @from and @to name a group, layer, shape or instance; with anchor auto the line is cut where it leaves the start node's box and enters the end node's box, less fromGap and toGap. route straight, orthogonal (axis-aligned elbows) or curved (bend in degrees); @points are waypoints. A connector has no box and no transform of its own.

    Content

    • one ofany number
      • <animate>
      • <expression>
      • <mask>

    AttributeTypeDefaultDescription
    declared here
    fromxs:IDREF

    Id of the group, layer, shape or instance where the line starts (same composition or symbol, not in a repeat, not 2.5D). Absent: the point fromX, fromY. If the node is absent at a frame, nothing is drawn.

    toxs:IDREF

    Id of the group, layer, shape or instance where the line ends (same composition or symbol, not in a repeat, not 2.5D). Absent: the point toX, toY. If the node is absent at a frame, nothing is drawn.

    fromAnchorconnectorAnchorTypeauto

    Point of the start node's box the line attaches to: auto (centre; line cut at the box edge if the box has nonzero size), center, a side or a corner (not cut). A keyword other than auto excludes fromX/fromY.

    toAnchorconnectorAnchorTypeauto

    Point of the end node's box the line attaches to: auto (centre; line cut at the box edge if the box has nonzero size), center, a side or a corner (not cut). A keyword other than auto excludes toX/toY.

    fromXlengthType

    With from: horizontal offset of the start inside the node's box, from its left edge (px, %, or viewport units; % is of the box width); the line is not cut. Without from: the start point's x (% is of the parent width).

    fromYlengthType

    With from: vertical offset of the start inside the node's box, from its top edge (px, %, or viewport units; % is of the box height); the line is not cut. Without from: the start point's y (% is of the parent height).

    toXlengthType

    With to: horizontal offset of the end inside the node's box, from its left edge (px, %, or viewport units; % is of the box width); the line is not cut. Without to: the end point's x (% is of the parent width).

    toYlengthType

    With to: vertical offset of the end inside the node's box, from its top edge (px, %, or viewport units; % is of the box height); the line is not cut. Without to: the end point's y (% is of the parent height).

    fromGapnonNegativeDecimal0

    Distance in pixels, measured along the route, by which the visible line is pulled back from the start (after any cut at the start node's edge). Default 0.

    toGapnonNegativeDecimal0

    Distance in pixels, measured along the route, by which the visible line is pulled back from the end (after any cut at the end node's edge). Default 0; the line vanishes if the gaps overlap.

    routeone of straight orthogonal curvedstraight

    Shape of the line between the ends: straight (through any points), orthogonal (axis-aligned elbows), or curved (one smooth curve shaped by bend). Default straight. Provisional (SREP 93): Routing method; curved routes use the shared SREP 58 length measure with 32 samples per true curve piece.

    pointspointListType

    Waypoints as x,y pairs in pixels in the connector's own space (where its siblings' x and y are given). The line passes through them in order; not allowed with route curved.

    bendxs:double in [-90, 90]30

    For route curved: angle in degrees (-90 to 90) between the chord and the curve's end tangents. Positive bulges left of the direction of travel, negative right, 0 is straight. Default 30.

    strokepaintType#FFFFFFFF

    Paint of the line; a colour, or a gradient or pattern spread over the bounding box of the line after cuts and gaps (before any trim). Default opaque white.

    strokeWidthnonNegativeDecimal4

    Line thickness in pixels, centred on the path. 0 draws nothing. Default 4.

    strokeCapstrokeCapTypebutt

    Shape of the line ends: butt (flat, default), round or square (flat, extended by half the width).

    strokeJoinstrokeJoinTypemiter

    Shape of corners where line segments meet: miter (sharp, default), round or bevel (cut off).

    miterLimitpositiveDecimal4

    Longest allowed miter point, as a ratio of miter length to line width; a sharper corner is drawn beveled instead. Applies to strokeJoin miter. Default 4.

    dashnumberListType

    Lengths in pixels of alternating dashes and gaps along the line; an odd number of values repeats the list. Absent: a solid line.

    dashOffsetxs:double0

    How far into the dash pattern, in pixels, the line starts; shifts the dashes along the line. Default 0.

    blendblendTypenormal

    Blend mode used to composite the connector over what lies beneath it. Default normal.

    effectsxs:IDREFS

    Space-separated ids of effects, defined in the scene's effects, that are applied to the drawn connector.

    labelxs:IDREF

    Id of a text asset drawn centred on the line, above the stroke, at the position set by labelAt and labelOffset.

    labelAtunitDecimal0.5

    Where along the line the label sits, as a fraction from 0 (start) to 1 (end) of the part left after cuts and gaps; trim does not move it. Default 0.5.

    labelOffsetxs:double0

    Distance in pixels to shift the label sideways from the line; positive moves it to the right of the direction of travel (down for a line running left to right). Default 0.

    labelOrientone of horizontal alonghorizontal

    horizontal keeps the label unrotated (default); along turns it to follow the line's direction at the label point, flipped when it would read upside down.

    Provisional (SREP 93): Human label for render-report findings and debug output, with no effect on geometry or colour.

    tagsxs:NMTOKENS

    Space-separated free-form labels on the node. With safeArea enforcement on, a node tagged cta or logo is checked to stay inside the safe region unless safeAreaForce exempts it.

    safeAreaForcexs:booleanfalse

    true exempts this node and everything it contains (for a symbol: every instance of it, and what it draws) from the safeArea enforce check (SA01); validate lists every node that carries it (SA02), so a deliberate placement outside the safe region is never silent.

    zxs:int0

    Stacking order among siblings: nodes with a higher integer draw above lower ones; 0 when absent. Not used for stacking by 3D objects, 3D particle nodes, ocean nodes and cameras.

    visiblexs:booleantrue

    When false, the node and everything it contains are not drawn; true when absent.

    opacityunitDecimal1

    Node opacity from 0 (transparent) to 1 (opaque), multiplied with the opacity of its ancestors; 1 when absent. Provisional (SREP 93): Own evaluated opacity and copy opacity factors are restricted to 0 through 1, with NaN treated as zero.

    startxs:double0

    Time in seconds, on the parent's timeline, at which the node first appears; 0 when absent. Added to the marker time when startMarker is set. A transition on the node can make it appear earlier.

    endxs:double

    Time in seconds, on the parent's timeline, at which the node disappears (exclusive); when absent it stays until its parent ends. Added to the marker time when endMarker is set. A transition can keep it longer.

    shutterAnglexs:double in [0, 720]

    The shutter angle, in degrees, of this node's motion blur, instead of the project's: the nearest node up its parents that sets it, else project/@shutterAngle. 0 draws the node sharp; 360 blurs over the whole frame interval. Only where motion blur is on for the node.

    startMarkerxs:NCName

    Name of a scene marker, or a beat.N or bar.N id of the beat grid, whose time is added to start to give the node's appearance time.

    endMarkerxs:NCName

    Name of a scene marker, or a beat.N or bar.N id of the beat grid, whose time plus end (0 if absent) gives the node's disappearance time.

    conditionexpressionString

    Node is rendered only when the expression is truthy (e.g. "param('showPrice')").

    motionBlurtriStateTypeinherit

    Turns motion blur on or off for this node and the nodes it contains; inherit (the default) takes the nearest ancestor's setting, then the project's.

    mattexs:IDREF

    Track matte: any node whose alpha or luma gates this node. The matte node is not drawn itself unless matteVisible="true".

    matteModematteModeTypealpha

    How the matte node gates this node: alpha or luma takes the matte's alpha or brightness as coverage, and the -inverted modes use one minus it; alpha when absent.

    matteVisiblexs:booleanfalse

    On a node that names a matte: when true the matte node is also drawn; by default (false) the matte is hidden and only gates this node.

    edgeBlendone of inherit linear encodedinherit

    The space in which this node's own pixels (their colour C and coverage x opacity a) composite onto what lies beneath (B): linear, out = a C + (1 - a) B in the linear working space; encoded, the same on display-encoded values (the sRGB transfer function), decoded back; inherit, linear when project/@linearLight is true and encoded when it is false. A group's value applies when its offscreen composites; children do not inherit it. SREP 72.

    from attribute group trimPath
    trimStartunitDecimal0

    Start of the visible part of the outline as a fraction 0-1 of its length; default 0. If start exceeds end, the two are swapped. A shape's fill is cut to the trimmed outline too.

    trimEndunitDecimal1

    End of the visible part of the outline as a fraction 0-1 of its length; default 1 (the full length). If end is below start, the two are swapped. A shape's fill is cut to the trimmed outline too.

    trimOffsetxs:double0

    Shifts the visible range along the outline in degrees, where 360 is one full length; the range wraps past the end. Default 0.

    trimModeone of simultaneous sequentialsimultaneous

    How trimming treats several subpaths: simultaneous (default) trims each by the same fractions, sequential trims across them as one continuous path.
