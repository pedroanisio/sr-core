    projectType

    Type of <project> in <scene>

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    width requiredxs:positiveInteger

    Width in pixels of the composition frame; an output is delivered at it unless the output gives its own width, selects a layout, or the document has a scene360.

    height requiredxs:positiveInteger

    Height in pixels of the composition frame; an output is delivered at it unless the output gives its own height, selects a layout, or the document has a scene360.

    fps requiredfpsType

    Frame rate in frames per second, an integer or a fraction such as 30000/1001.

    duration requireddurationType

    Length of the composition in seconds; content outside 0 to duration is never drawn.

    seedxs:unsignedLong0

    Document-wide seed for procedural randomness; random elements without their own seed derive theirs from it, so renders are reproducible. 0 when absent.

    linearLightxs:booleantrue

    Default blending space: when true, nodes composite on linear-light values, when false on encoded values; a node's edgeBlend can override it. true when absent.

    workingColorSpacecolorSpaceTypesrgb

    Colour space in which the frame is composited; srgb when absent. Any colorManagement element replaces it with its own workingSpace (linear-srgb by default).

    backgroundpaintType#000000FF

    Paint drawn behind the whole composition; opaque black when absent. A visible gradient-sky dome light replaces it when no 3D node is drawn.

    antialias3dxs:positiveInteger ≤ 41

    Provisional (SREP 93): Multisample count for 3D raster passes: 1, 2 or 4 samples, with 3 selecting 4 and default 1 leaving output unchanged.

    precisionone of f16 f32f16

    Working textures (offscreens, effect passes, persistent buffers, the frame): f16 or f32 per channel. SREP 72.

    supersamplexs:positiveInteger ≤ 41

    n > 1 renders the frame at n x width by n x height, every length scaled by n, and filters it down with supersampleFilter: output pixel i is the weighted mean of the samples, sample k centred at (k + 0.5)/n output pixels, the weights renormalised at the frame's edges, in the working space before output encoding, and clamped to [0, max(1, M)], M the largest sample of non-zero weight. SREPs 72 and 89.

    supersampleFilterone of box lanczos3box

    box: the mean of the n x n samples inside the pixel; lanczos3: the separable kernel sinc(x) sinc(x/3) for |x| < 3 output pixels. Read only when supersample > 1. SREP 72.

    motionBlurxs:booleanfalse

    Whether nodes are motion-blurred by default; a node's own motionBlur on/off, or its nearest ancestor's, overrides it. false when absent.

    shutterAnglexs:double in [0, 720]180

    Shutter opening in degrees of the frame interval (180 exposes half a frame; 0 disables blur); a node's own shutterAngle overrides it. 180 when absent.

    shutterPhasexs:double-90

    Offset of the shutter opening from the frame time, in degrees of the frame interval; negative values start before the frame. -90 when absent.

    motionBlurSamplesxs:positiveInteger ≤ 25616

    Number of time samples averaged for motion blur (1 to 256), further limited by the quality tier; 16 when absent.

    adaptiveMotionBlurxs:booleantrue

    When true, a node that barely moves across the shutter is not blurred, which saves work; when false such a node is still sampled, except still groups and adjustment layers, which never are. true when absent.

    timecodeStarttimecodeType

    Provisional (SREP 93): Starting container timecode at the project frame rate, with semicolon notation selecting drop-frame timecode.

    pixelAspectpositiveDecimal1

    Provisional (SREP 93): Output sample aspect ratio tag, default 1, applied without resampling the rendered frame.

    safeAreaxs:IDREF

    Id of the safeArea checked for text, captions and nodes tagged cta or logo; the selected layout's safeArea replaces it, as does a caption track's own for that track's captions.

    qualityone of draft preview finalfinal

    Render quality tier: final as authored; preview at full size with at most 4 motion-blur samples; draft at half size with fewer samples and no grain or noise. final when absent.

    fontPolicyone of system pinnedsystem

    system lets text use the host's fonts; pinned restricts text to the document's own font assets, which must be pinned by hash, so layout is reproducible. system when absent.
