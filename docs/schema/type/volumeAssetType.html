    volumeAssetType

    Type of <volume> in assetsType

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Name by which an object3D's volume attribute refers to this volume.

    src requiredvolumeSourceType

    Path of a local volume cache file (or of the manifest for srvseq), or a numbered pattern (such as frame_%04d.srvol or frame_####.srvol) for a sequence, which also needs first and last.

    sha256sha256Type

    SHA-256 of the cache file, or of the manifest of an srvseq bake (required there); a mismatch is an error. Not allowed on a numbered sequence.

    formatone of srvol srvseq openvdbsrvol

    File format of the cache: srvol or openvdb (each a single file or a numbered sequence), or srvseq (a baked sequence with a manifest); srvol when absent.

    densityGridvolumeChannelTypedensity

    Name of the cache channel read as density; density when absent.

    temperatureGridvolumeChannelType

    Name of the cache channel holding temperature in kelvin, which blackbody emission reads and which a medium with blackbody requires; the channel must exist in every frame and have no negative samples.

    velocityGridXvolumeChannelType

    Name of the channel with the x component of the velocity, in the cache's own world units per second (before the object's transform), that interpolation advect follows. Required with advect, else not allowed.

    velocityGridYvolumeChannelType

    Name of the channel with the y component of the velocity, in the cache's own world units per second (before the object's transform), that interpolation advect follows. Required with advect, else not allowed.

    velocityGridZvolumeChannelType

    Name of the channel with the z component of the velocity, in the cache's own world units per second (before the object's transform), that interpolation advect follows. Required with advect, else not allowed.

    firstvolumeFrameIndexType

    Frame number of the first file of a numbered sequence; requires last (not before first, under 1,000,000 frames after it) and a numbered src pattern. Not allowed with the srvseq format.

    lastvolumeFrameIndexType

    Frame number of the last file of a numbered sequence; not below first, and the run holds at most 1,000,000 frames.

    fpsfpsType

    Frame rate of the numbered sequence; the project's frame rate when absent. Only for sequences.

    interpolationvolumeInterpolationTypehold

    How a time between two sequence frames is sampled: hold keeps the earlier frame, linear blends both, advect moves the fields along the velocity channels. hold when absent; a single cache file accepts only hold.

    missingFramevolumeMissingFrameTypeerror

    What a missing frame file becomes: error fails the render, hold uses the nearest earlier frame (an error if none exists), transparent is an empty frame. error when absent.

    boundsMinXxs:double

    Lower x limit of a box, in the cache's own coordinates before the object's transform, outside which the volume is not rendered; all six bounds must be given together.

    boundsMinYxs:double

    Lower y limit of a box, in the cache's own coordinates before the object's transform, outside which the volume is not rendered; all six bounds must be given together.

    boundsMinZxs:double

    Lower z limit of a box, in the cache's own coordinates before the object's transform, outside which the volume is not rendered; all six bounds must be given together.

    boundsMaxXxs:double

    Upper x limit of a box, in the cache's own coordinates before the object's transform, outside which the volume is not rendered; must exceed boundsMinX.

    boundsMaxYxs:double

    Upper y limit of a box, in the cache's own coordinates before the object's transform, outside which the volume is not rendered; must exceed boundsMinY.

    boundsMaxZxs:double

    Upper z limit of a box, in the cache's own coordinates before the object's transform, outside which the volume is not rendered; must exceed boundsMinZ.
