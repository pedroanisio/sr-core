    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Unique identifier that layers use to show this chart.

    kind requiredone of bar column line area pie donut scatter counter progress

    Chart type: bar, column, line, area, pie, donut, scatter, counter (a number counting from the first value to the second, or from 0 to a single value) or progress (a fill bar). An unknown kind draws a column chart.

    width requiredxs:positiveInteger

    Width of the chart image in pixels.

    height requiredxs:positiveInteger

    Height of the chart image in pixels; the default label size is one eighteenth of it, limited to 10 to 28 pixels.

    labelsxs:string

    Comma-separated category labels, one per position along the category axis of bar, column, line, area and scatter charts; pie, donut, counter and progress draw none. Absent: taken from src.

    srcxs:anyURI

    Local CSV (first column labels, header row series names) or JSON (labels, and series with name and values). Supplies labels when labels is absent and series when no series children are given.

    textStylexs:IDREF

    Id of the text style used for axis labels, category labels and values; by default white text sized from the chart height.

    progressunitDecimal1

    How much of the data is drawn, from 0 (none) to 1 (all); bars grow, lines trace, slices sweep, scatter points appear, counters run from their start value, a progress bar fills. Axes and labels stay. Default 1.

    showAxesxs:booleantrue

    Whether the axis lines of cartesian charts are drawn, with value ticks on every kind except bar. Default true.

    showValuesxs:booleanfalse

    Whether the numeric value is printed on each bar, line or area point and pie or donut slice, and on a progress bar. Scatter points get none. Default false.

    formatxs:string

    Number pattern for values and axis ticks such as 0.0, #,##0, 0% or $#,##0.00 (or %.2f); decimals follow the pattern, a comma groups thousands, a trailing % scales by 100. Absent: whole numbers or up to two decimals.
