    generatedAssetType

    Type of <generated> in assetsType

    Media produced by an external generator (text-to-speech, image, video or music model, transcription). The renderer never calls the provider while rendering: it reads @cache and fails unless the file's SHA-256 equals @cacheSha256. A resolve step, run before rendering, fills the cache from @provider/@model/@prompt/@voice/@seed and pins @cacheSha256. This keeps renders deterministic.

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Unique identifier by which layers and audio tracks refer to the generated media.

    kind requiredone of image video speech music sound-effect

    What the generator produces: image, video, speech, music or sound-effect. Images and videos draw as visuals; the audio kinds play on audio tracks.

    provider requiredxs:string

    Name of the generator that makes the media. It is called only by the resolve step, never while rendering.

    model requiredxs:string

    Model, voice or cue name handed to the provider; what it selects depends on the provider.

    promptxs:string

    Text the provider generates from: the words to speak for speech; for other kinds a description or parameters, as the provider defines. Required for every kind except speech, though built-in speech providers need it.

    voicexs:string

    Voice the provider uses for speech: a voice name, voice id or speaker number depending on the provider. Some providers require it; others fall back to a default voice.

    languagelanguageTagType

    Language of the generated speech, as a tag such as en or pt-BR, sent with the request; a provider that uses it reads only the primary subtag.

    seedxs:unsignedLong

    Whole-number seed sent with the request; only some providers use it. It is part of what identifies a cached result.

    cache requiredxs:anyURI

    File holding the generated media. Rendering reads this file and never calls the provider; the resolve step writes it.

    cacheSha256 requiredsha256Type

    SHA-256 of the cache file, 64 lowercase hex digits. A mismatch is a validation error, and the resolve step rewrites it after generating.

    widthxs:positiveInteger

    Requested width in pixels of a generated image or video; only together with height is it also the media's size when laid out.

    heightxs:positiveInteger

    Requested height in pixels of a generated image or video; only together with width is it also the media's size when laid out.

    fpsfpsType

    Frame rate of a generated video, in frames per second (an integer or a ratio such as 30000/1001). If absent it is read from the file, or taken as 25 when the file cannot be probed.

    durationpositiveDecimal

    Requested length in seconds, sent to the provider with the request; whether a provider uses it depends on the provider.

    licensexs:string

    Licence of the generated asset as free text; copied into the render report's asset credits and never checked.
