    cameraType

    Type of <camera>
    in 7 typesgroupType, sequenceType, repeatType, viewport3DType, iterateType, compositionType, symbolType

    Physical camera: when focalLength is set, fov derives from focalLength and sensorWidth (mm). depthOfField uses fStop, focusDistance (scene units) and apertureBlades. Several cameras may exist; the active one at time t is the last active camera whose [start, end) contains t (camera switching).

    Horizontal field of view in degrees, across the frame width: the focal distance in pixels is (frame width / 2) / tan(fov / 2), whatever the frame's height, so a portrait frame sees a narrower vertical angle than a landscape one.

    Distance in scene units from the camera of the farthest drawn surface; default 10000. A camera with renderer pathtrace does not clip at it.

    geodesicsxs:booleanfalse

    Version 1.3. true renders the scene by tracing each camera ray along a null geodesic of the Schwarzschild spacetime of the scene's blackHole (BH5): the shadow, the lensed image of the background and of the accretionDisk. This version renders only the black hole, its disk and the 2D background: any object3D, particles3D, particleEmitter, ocean, fluid, flock, slime, erosion, pyro or medium in the scene is an error (BH6), the camera is farther than 3 mass from the hole (BH7) and is the only one with geodesics (BH8); 2D layers, text, shapes, effects and adjustments are allowed, and the image goes through the 2D chain. The camera's distance to the hole is the radius of the static observer. fov, roll, target, yaw and pitch are those of any camera and pathSamples is the number of antialiasing samples of a pixel; denoise="true" and lights are not used (W12, W05). false (the default) is the camera there always was, and a blackHole or an accretionDisk with it is not rendered (W11).

    pathSamplesxs:positiveInteger ≤ 6553664

    Samples per pixel of the path tracer, 1 to 65536, default 64. With geodesics it is instead the antialiasing sample count of a pixel, 1 to 4096, default 16. Provisional (SREP 93): Path-tracing sample count; geodesic cameras use 1 to 4096, default 16, and report a warning when a supplied value exceeds 4096.

    maxBouncesxs:positiveInteger ≤ 644

    Maximum light bounces per path of the path tracer, 1 to 64; default 4.

    denoisexs:booleantrue

    Whether the path-traced image is denoised; default true. Ignored with geodesics.
