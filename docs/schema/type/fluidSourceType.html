    fluidSourceType

    Type of <fluidSource> in fluidType

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    xxs:double0

    Horizontal position of the source in pixels within the fluid box; default 0.

    yxs:double0

    Vertical position of the source in pixels within the fluid box; default 0.

    radiuspositiveDecimal20

    Radius in pixels of the source; its effect fades linearly to zero at the edge. Default 20.

    colorpaintType#FFFFFFFF

    Colour of the dye it injects; only a literal colour is used (any other paint falls back to white). Default white.

    densitynonNegativeDecimal1

    Amount of dye injected per second at the centre; 0 injects none. Default 1.

    velocityXxs:double0

    Horizontal velocity in pixels per second that the source pushes the fluid toward within its radius; default 0.

    velocityYxs:double0

    Vertical velocity in pixels per second that the source pushes the fluid toward within its radius; default 0.

    startxs:double0

    Time in seconds, on the fluid clock, at which the source switches on; default 0.

    endxs:double

    Time in seconds, on the fluid clock, at which the source switches off (exclusive); absent, it stays on.
