    type required
    one of 14 valuesbend twist wave squash stretch mesh-warp puppet skin bulge pinch spherize ripple turbulence corner-pin

    The deformation: bend, twist, wave, squash, stretch, mesh-warp, puppet, skin (needs skeleton), bulge, pinch, spherize, ripple, turbulence or corner-pin (needs corners).

    amountxs:double0

    Strength of the effect, default 0 (none): degrees for bend and twist, pixels for wave, ripple and turbulence, a fraction for squash, stretch, bulge, pinch and spherize (spherize clamps to -1..1).

    frequencyxs:double1

    Wave: number of cycles across the box. Ripple and turbulence: waves or noise features per 100 pixels. Default 1; ignored by other types.

    phasexs:double0

    Shifts the pattern: a phase in degrees for wave and ripple, a scroll of the noise field for turbulence. Default 0; ignored by other types.

    axisxs:stringy

    Direction, x or y (default y; any other value acts as y), along which bend and wave displace points and squash and stretch scale.

    rowsgridSizeType4

    Mesh-warp: number of control-point rows in the warp grid (2 to 16, default 4); the point children address them by row.

    colsgridSizeType4

    Mesh-warp: number of control-point columns in the warp grid (2 to 16, default 4); the point children address them by col.

    centerXxs:double

    Horizontal centre of the effect in pixels from the left of the node's box; defaults to the middle of the box. Used by bend, twist, squash, stretch, bulge, pinch, spherize and ripple.

    centerYxs:double

    Vertical centre of the effect in pixels from the top of the node's box; defaults to the middle of the box. Used by bend, twist, squash, stretch, bulge, pinch, spherize and ripple.

    radiusnonNegativeDecimal

    Reach in pixels around the centre, fading to nothing at the edge (twist, bulge, pinch, spherize, ripple). Defaults to half the shorter box side; for ripple, absent means no fade.

    seedxs:unsignedLong

    Turbulence only: seed of the noise field; the same seed gives the same displacement. Default 0.

    skeletonxs:IDREF

    Skin only: the id of the skeleton whose bones deform the node. A reference that names no skeleton leaves the node undeformed.

    cornersnumberListType

    corner-pin: 8 numbers x0 y0 x1 y1 x2 y2 x3 y3 (TL, TR, BR, BL).
