    sequenceType

    Type of <sequence> in groupType, sequenceType, repeatType, iterateType, compositionType, symbolType

    Children play one after another: each child's start is the previous child's end plus @timeGap seconds (negative values overlap). A child's own start is an additional offset. If @transition is set, every junction gets that transition with @transitionDuration unless an explicit transition exists.

    Extends groupType.

    declared here
    timeGapxs:double0

    Seconds between the end of one child and the start of the next in the sequence; negative values overlap them. A child with a startMarker is not repositioned by the sequence. Default 0.

    transitionxs:NMTOKEN

    Transition type automatically inserted at each junction that has no explicit transition; absent, junctions stay cuts. The inserted ones take default options, so shader falls back to a crossfade.

    transitionDurationpositiveDecimal0.5

    Length in seconds of the automatic transitions, centred on the cut between children; default 0.5.
