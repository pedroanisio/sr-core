    audiogramAssetType

    Type of <audiogram> in assetsType

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Unique identifier that layers use to show this audiogram.

    source requiredxs:IDREF

    Id of the audio track whose loudness drives the audiogram.

    width requiredxs:positiveInteger

    Width of the audiogram image in pixels.

    height requiredxs:positiveInteger

    Height of the audiogram image in pixels.

    styleone of bars line wave circle spectrumbars

    Drawing style: bars, line, wave or circle show the recent loudness history; spectrum shows low, mid and high band levels across the bars. Default bars.

    barsxs:positiveInteger48

    Number of bars or points, at least 2: recent loudness samples, or positions along the spectrum. Default 48.

    colorpaintType#FFFFFFFF

    Colour or paint of everything drawn: the bars, line, wave or circle rays. Default opaque white.

    smoothingunitDecimal0.5

    Smoothing of the loudness history from 0 (none) to 1 (strongest, capped just below 1); higher values react more slowly. The spectrum style ignores it. Default 0.5.
