    trackDataType

    Type of <trackData> in trackingType

    Content

    Empty: attributes only.

    Attributes

    AttributeTypeDefaultDescription
    declared here
    id requiredxs:ID

    Identifier of the tracking data; track constraints and tracked attachments name it as their target.

    src requiredxs:anyURI

    Path of the tracking file to read; only local files are supported, and a file that cannot be read or parsed is an error.

    kind requiredone of point planar camera mask face

    What the file tracks, required. The file must hold a matching series (points or planes for point, mask and face; planes for planar; cameras for camera), else error E17; only point, planar, mask and face may drive a transformConstraint or a layer's stabilize.

    formatone of json csv nuke after-effects mocha fbxjson

    File format of the tracking data: json (default), csv, nuke, after-effects, mocha or fbx.

    footagexs:IDREF

    Id of the footage asset the data was tracked on; when a layer plays it, track points map from its pixels into the frame through that layer and follow its source time, otherwise they are used as given.

    timeOffsetxs:double0

    Seconds added to the time at which the tracking data is sampled, shifting the track against the footage; defaults to 0.

    sha256sha256Type

    Expected SHA-256 digest of the file at src; when assets are verified, a different digest is error A02.
