    tilesAssetType

    Type of <tiles> in assetsType

    Map tiles: a PMTiles archive (@src) of vector (MVT) or raster (PNG, JPEG, WebP) tiles; or an online tile service (@url, a template with {z}, {x} and {y}, or {s} for a subdomain), whose tiles a resolve step, run before rendering, downloads for the views the document's maps show into @cache (a PMTiles archive pinned by @cacheSha256). Rendering never fetches tiles. @sha256 pins @src. @tileSize is the pixel size tiles are drawn at (default 512 for vector tiles, 256 for raster); @minZoom and @maxZoom (minZoom <= maxZoom) bound the zooms fetched from a service. @attribution is the tiles' credit line.

    Content

    Empty: attributes only.

    id requiredxs:ID

    Identifier by which basemaps, and the terrain of a 3D map object, name this tile source.

    srcxs:anyURI

    Path or URI of a local PMTiles archive of vector or raster tiles that is read when rendering; used in preference to the cache.

    sha256sha256Type

    SHA-256 digest that the file named by src must match; a mismatch is reported as an error when the document is checked.

    urlxs:string

    Template of an online tile service with {z}, {x} and {y} (and {s}, which takes a, b or c); the resolve step downloads the needed tiles into cache, and rendering never does. Without src it needs cache and cacheSha256.

    cachexs:anyURI

    Path of the PMTiles archive the resolve step writes from url; it is read for rendering when src is absent. Required with url unless src is given.

    cacheSha256sha256Type

    SHA-256 digest that pins the cache archive; a mismatch is reported as an error when assets are verified, and the resolve step writes it. Required with url unless src is given.

    tileSizexs:positiveInteger

    Pixel size at which a basemap draws these tiles and at which zooms to fetch are chosen; 512 for vector tiles and 256 for raster when absent. Not used for 3D terrain or buildings.

    minZoomtileZoomType0

    Lowest zoom level (0 to 24) fetched from the online service; 0 when absent. It does not limit tiles read from src.

    maxZoomtileZoomType19

    Highest zoom level (0 to 24) fetched from the online service; 19 when absent, and not below minZoom. It does not limit tiles read from src.

    attributionxs:string

    Credit line for the tiles, drawn in the map's corner by a basemap that shows its attribution; the archive's own credit is used when absent.
