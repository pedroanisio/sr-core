    Which colour description of a still image file applies. embedded: an ICC profile (matrix/TRC) or H.273 code points (HEIF nclx, ICC cicp) in the file take precedence over colorSpace and transfer, which apply to files without one. declared: colorSpace and transfer always apply (data textures, mis-tagged files).

    projectionType

    Map projections (d3-geo formulas). Cylindrical, pseudo-cylindrical and conic projections cut the globe along the antimeridian opposite the centre; orthographic and the azimuthal projections clip to the visible cap (the near hemisphere for orthographic). web-mercator is spherical Mercator with MapLibre zoom levels (a 512-pixel world at zoom 0).

    one of mercator web-mercator equirectangular equal-earth natural-earth albers lambert-conformal orthographic stereographic azimuthal-equal-area azimuthal-equidistant

    Used by mapAssetType.
