    Conventions

    scene-render scene format 1.1. This schema is the interchange contract
shared by every scene-render engine. Its
canonical copy is sr-core/schema/; it changes only through an accepted
SREP (sr-core/srep/). Every document valid under 1.0 is valid
under 1.1 (with one exception: colour channels above 1, which 1.0 matched
by accident, are now rejected). New sections, elements and asset kinds
require version="1.1"; new attributes on 1.0 elements are accepted in both
versions. The companion Schematron rules (scene-render.sch) enforce the
version gate and the cross-field rules XSD 1.0 cannot express.

Conventions used everywhere:
  time      seconds (xs:double) on the composition timeline unless stated;
  space     2D pixels, origin top-left, +x right, +y down;
  angles    degrees, positive = clockwise on screen;
  physics   metres, +y up, mapped to pixels by physics/@pixelsPerMeter;
  colour    straight (non-premultiplied) alpha in the working space;
  lengths   a lengthType accepts pixels or %, vw, vh, vmin, vmax
            (percent is relative to the parent box; vw/vh to the output frame).
Determinism: every random, noise, wiggle, generated or transcribed value is
a pure function of project/@seed, the element's own seed and the frame
time. Anything that needs an external service is resolved from a declared
cache whose content hash is part of the document.
